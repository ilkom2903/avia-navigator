# АвиаНавигатор

Простой веб-приложение-опросник для профориентации в гражданской авиации.

## Как запустить

Откройте файл `index.html` в браузере.

## Что это

- 7 вопросов
- 11 возможных направлений карьеры
- Автоматический подсчет результата
- Поделиться результатом
- Анимация и фирменный дизайн в стиле авиакомпании

## Развертывание

Можно открыть через GitHub Pages или любой статический веб-сервер.
